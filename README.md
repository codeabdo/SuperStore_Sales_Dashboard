# SuperStore Sales Dashboard

An interactive sales dashboard built in Excel using Power Pivot and the Data Model (Star Schema).

## Key Metrics
- Total Sales, Total Quantity, Avg Discount, Total Profit, Total Orders

## Visuals
- Sales by Category
- Sales by Region
- Sales and Profit Trend (2014–2017)
- Profit by Segment
- Profit by Ship Mode
- Top 5 States in Sales

## Interactivity
Slicers for Year, Category, Segment, and Region.

## Tools Used
- Excel (Power Query, Power Pivot, PivotCharts, Slicers)
